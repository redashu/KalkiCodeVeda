# KalkiCodeVeda

> **R&D repository for Udemy course content creation**

## About

**KalkiCodeVeda** is a research-and-development (R&D) repository maintained by the [Delvex Community](https://github.com/delvex-community). It serves as the central workspace for building, experimenting with, and refining the code samples, projects, and exercises that appear in Udemy video courses.

The name is inspired by two ideas:
- **Kalki** – the forward-looking, transformative spirit of continuous learning.
- **CodeVeda** – treating code as a *veda* (a body of knowledge) to be studied, practised, and shared.

---

## Purpose

| Goal | Description |
|------|-------------|
| 📚 Course R&D | Prototype and iterate on code examples before recording |
| 🎬 Udemy Content | Source of truth for all code shown in video lectures |
| 🧪 Experimentation | Try out new technologies, patterns, and best practices |
| 📝 Reference Material | Provide learners with a clean, well-organised codebase to follow along |

# How to run terraform code 

```bash
cd sample

terraform init 
terraform plan 
terraform apply 

# To destroy resources 

terraform destroy 
```
